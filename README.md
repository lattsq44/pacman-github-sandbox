# 🍒 Square44 Pac-Man: สนามซ้อมเข้าใจการทำงานของ Git & GitHub แบบเห็นภาพจริง!

โปรเจกต์นี้สร้างขึ้นเพื่อให้พี่ๆ น้องๆ ในทีมได้ทดลองเล่นและเข้าใจว่า **"ทำไมเวลาเราทำงานด้วยกัน เราถึงใช้ GitHub จัดการไฟล์ และมันทำงานยังไง?"** โดยไม่ต้องกลัวทำระบบงานจริงพังครับ!

## 🧩 1. ทำไมเราต้องแยกไฟล์ออกเป็นชิ้นๆ? (Modular Files)
ลองดูในโฟลเดอร์นี้ จะเห็นว่าตัวเกมถูกแยกออกเป็น **4 ไฟล์หลัก** ตามหน้าที่:

| ชื่อไฟล์ | หน้าที่ของไฟล์ | ถ้าอยากลองซ้อมแก้ ให้ทำอะไร? |
| :--- | :--- | :--- |
| **`config.js`** | เก็บค่าตั้งต้น (จำนวนชีวิต, ความเร็ว, สีผี, ชื่อคนแก้) | ลองเปิดไฟล์นี้แล้วแก้ `INITIAL_LIVES: 3` เป็น `99` หรือแก้ชื่อตัวเองใน `LAST_EDITED_BY` |
| **`map.js`** | เก็บตารางแผนที่เขาวงกต (`1` = กำแพง, `0` = จุดกิน) | ลองเปลี่ยนเลข `1` เป็น `0` เพื่อทุบกำแพงเปิดทางลัดในเขาวงกต |
| **`style.css`** | เก็บสีพื้นหลังและหน้าตาเว็บ | ลองเปลี่ยนสีกรอบตารางหรือสีป้ายคะแนน |
| **`game.js` / `index.html`** | ตัวเครื่องยนต์เกมหลัก | ดับเบิลคลิกที่ **`index.html`** เพื่อเปิดเล่นเกมบนเบราว์เซอร์ได้ทันที! |

## 🚀 2. จำลองสถานการณ์จริง: GitHub จัดการไฟล์ยังไงเวลาทำหลายคน?

ลองนึกภาพว่าเรามีเพื่อน 2 คนช่วยกันทำเกมนี้:
- **คนที่ 1 (สมมติชื่อเอ)** อยากปรับความเร็วผีและเพิ่มชีวิต -> เอก็เปิดแก้แค่ไฟล์ **`config.js`**
- **คนที่ 2 (สมมติชื่อบี)** อยากออกแบบด่านเขาวงกตใหม่ -> บีก็เปิดแก้แค่ไฟล์ **`map.js`**

### คำศัพท์ GitHub 4 คำที่ต้องรู้ (เข้าใจใน 1 นาที):
1. **`Pull` (ดึงของล่าสุดลงมา):** ก่อนเริ่มทำงาน กดดึงไฟล์ล่าสุดจากกองกลางบน GitHub ลงมาที่เครื่องเราก่อน
2. **`Commit` (กดเซฟจุดบันทึกพร้อมเขียนโน้ต):** พอเราแก้ไฟล์ `config.js` เสร็จ เรากด Commit พร้อมเขียนข้อความสั้นๆ เช่น *"ปรับชีวิตเริ่มต้นเป็น 10 ตัว"* (เปรียบเหมือนการกด Save จุด Checkpoint ในเกม)
3. **`Push` (ส่งขึ้นกองกลาง):** ส่งจุดบันทึกที่เราทำเสร็จแล้วขึ้นไปเก็บไว้บน GitHub เพื่อให้เพื่อนคนอื่นดึงไปใช้ต่อได้
4. **`Revert / Rollback` (ย้อนเวลาเมื่อทำพัง):** ถ้าเผลอลบโค้ดผิดจนเกมเปิดไม่ติด ไม่ต้องตกใจ! ใน GitHub มีประวัติทุกครั้งที่กด Commit เราสามารถกดย้อนเวลากลับไปตอนที่เกมยังดีอยู่ได้ในคลิกเดียว!

## 🧪 3. แบบฝึกหัดลองทำจริง (ใช้เวลา 3 นาที)
1. ดับเบิลคลิกเปิดไฟล์ **`index.html`** จะเห็นเกม Pac-Man เล่นได้ทันที
2. คลิกขวาที่ไฟล์ **`config.js`** เลือกเปิดด้วย **Notepad** (หรือ VS Code)
3. ลองแก้บรรทัด:
   - `LAST_EDITED_BY: "ใส่ชื่อของคุณ"`
   - `INITIAL_LIVES: 9`
   - `PACMAN_COLOR: "#00FFAA"` (เปลี่ยนตัว Pac-Man เป็นสีเขียวนีออน)
4. กด **Save (`Ctrl + S`)** แล้วกลับไปหน้าเว็บเกม กด **Refresh (`F5`)** -> จะเห็นว่าชื่อคุณขึ้นบนหัวเว็บ และตัว Pac-Man เปลี่ยนสีทันที!
5. พอเข้าใจแล้ว ลองใช้คำสั่ง `git status` และ `git diff` (หรือดูในหน้าต่าง Source Control) จะเห็นเลยว่า Git ชี้ให้ดูชัดๆ ว่าบรรทัดไหนเปลี่ยนจากอะไรเป็นอะไร!
