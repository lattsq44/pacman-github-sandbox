# 🍒 Square44 Pac-Man // GitHub Sandbox

A modular Pac-Man game designed for the Square44 team to practice Git and GitHub workflows (`pull`, `commit`, `push`, and `revert`).

## 📂 Project Structure
- **`config.js`** — Game settings (starting lives, speed, colors, and editor badge).
- **`map.js`** — 2D maze array (`1` = Wall, `0` = Dot, `2` = Power Pellet, `9` = Empty Path).
- **`style.css`** — UI and theme styles.
- **`game.js` & `index.html`** — Core Pac-Man game engine and centered game board.
